# NLP Portfolio

## Project Structure

This repository contains various projects and resources related to Natural Language Processing (NLP). The structure of the portfolio is as follows:

1. **01-text-processing** - Basic text processing techniques.
2. **02-classical-nlp-tf-idf** - Classical NLP methods, including TF-IDF.
3. **03-word-embeddings** - Techniques for creating word embeddings.
4. **04-bert-and-transformers** - Applications of BERT and Transformer architectures.
5. **05-llm-applications** - Various applications of large language models (LLMs).
6. **06-information-retrieval** - Techniques in information retrieval systems.
7. **07-bias-evaluation** - Evaluating bias in NLP models.
8. **08-advanced-projects** - More advanced NLP projects and applications.

Feel free to explore and contribute!
